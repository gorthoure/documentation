## Выбор даты (`User Story 1`)

Для вывода блока с выбором даты используется функция `print_data_select` сам выбор даты из календаря производится через функцию `print_calendar_v2`, которая выводит html разметку и js обработчик через datetimepicker.

После выбора даты производится вызов функции `ltFn` с указанной датой (`Job Case 1`)

Если дата не задана - выводится список матчей за текущую дату через функцию функции `ltFn` (`Job Case 1`)

## Функция `ltFn`

Метод предназначен для выборки и отображения спортивных событий по заданному виду спорта и дате.

### Входные параметры


| Параметр | Тип    | Описание                                                                                                     |
|----------|--------|--------------------------------------------------------------------------------------------------------------|
| sport    | string | Название вида спорта (на английском языке). Если задано 'all', фильтрация по виду спорта не производится.    |
| date     | string | Дата в формате Y-m-d. Если дата совпадает с текущей датой, применяется текущая дата с учетом часового пояса. |


### Для каждого полученного события:

- Получаются участники (`fetchMatchParticipants`), запрос из таблицы `event_participants`.

- Получаются стадии турнира (`fetchMatchTournamentStages`), запрос из таблицы `tournament_stages`.

- В массив записываются данные турнира, страны, вида спорта, статуса, даты начала.

- Для каждого участника сохраняется имя, номер, ID команды

- Результаты для каждого участника получаются функцией `fetchParticipantResults`, запрос из таблицы `event_participants_result`

### Выходные данные:

- Если найдены события, отображаются три блока с аккордеонами:
- `lt_50` для вывода в 2 колонки
- `lt_100` для вывода в 1 колонку

- Если событий нет — отображается сообщение 'no_events_planned'.

# User case3 - просмотр страницы матча

Вход на эту страницу возможен только по клику на строку матча из блока `Job Story 1`, в ссылку передаётся id матча

## User Story 1

Просмотр календаря игр (аналогично блоку из `User case2`)

## User Story 2

Просмотр списка команд, участвующих в турнире (аналогично блоку из `User case2`)

## User Story 3

Просмотр данных по матчу состоит из 3-х блоков

- Вывод статистики встреч между командами и инцидентов, если предоставлены (`matches_widget_match`)
- Вывод данных о составе команд, если предоставлен, иначе не выводится блок и пункт переключения блоков (`matches_table_teams`)
- Вывод текстовой трансляции матча(замены, карточки, голы) если предоставлены, иначе не выводится блок и пункт переключения блоков (`matches_table_teams`)

---

## Функция `matches_widget_match`

Основная html разметка и вывод статистики

### Входные параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `m_id`   | int | ID матча |

### Вспомогательные функции

- `fetchMatchDetails`,`fetchMatchProperties` - получение подробных данных по матчу
- `fetchMatchParticipants` - получение участников матча
- `fetchParticipantResults` - получение данных о результатах матча
- `getMatchIncidents` - получение данных об инцидентах
- запрос в таблицу `events_venue` для получения данных о месте проведения

### Выходные данные

Метод генерирует HTML для отображения информации об инцидентах если они были, 
расписание встреч между командами-участниками матча.

## Функция `matches_table_commentaries`

Метод делает запрос в таблицу `events_commentaries` по ID матча и отображает комментарии к матчу, если они есть. 

### Входные параметры

| Параметр | Тип | Описание |
|----------|-----|----------|
| `m_id`   | int | ID матча |

!!----------
### Вспомогательные функции

- запрос в таблицу `events_commentaries` для получения данных о комментариях
- Если комментарии есть - выводится html разметка с текстом комментария и минутой
- Если комментариев нет - запрашиваются данные по матчу и выводится информация о начале и конце матча, а также об инцидентах 
через функции: 
  - `fetchMatchDetails`,`fetchMatchProperties` - получение подробных данных по матчу
  - `fetchMatchParticipants` - получение участников матча
  - `fetchParticipantResults` - получение данных о результатах матча
  - `getMatchIncidents` - получение данных об инцидентах
  - Для каждого инцидента выводится html разметка с данными о типе инцидента, номере и имени игрока


### Выходные данные

Метод генерирует HTML для отображения информации о комментариях или инцидентах
