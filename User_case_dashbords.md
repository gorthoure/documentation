## Получение данных, создание, обновление, удаление групп счётчиков (`User story 1`)

Для получения данных по созданным группировке счётчиков используется роут `counters/get/grouping`, 
функция `GetGrouping`(countersModel)

Для получения данных по счётчикам привязанным к группировке используется роут `counters/get/grouping/devices`, 
функция `GetGroupingDevices`(countersModel) 

Для получения данных по всем счетчикам садоводства, с указанием счётчиков привязанных к группировке используется роут 
`counters/get/grouping/devices/all`, функция `GetAllDevicesForGrouping`(countersModel)

Для создания группы счётчиков используется роут `counters/add/grouping`, id счётчиков передаются в массиве `counters`
- функция `AddGrouping`(countersModel) создаёт группировку
- функция `AddGroupingDevice`(countersModel) привязывает счётчики к созданной группировке

Для редактирования группировки используется роут `counters/edit/grouping` который:
- удаляет все привязанные счётчики функцией `DeleteGroupingDevice`(countersModel)
- привязывает счётчики к группировке функцией `AddGroupingDevice`(countersModel)
- если передано имя группировки - обновляет его функцией `EditGroupingName`(countersModel)

Для удаления группировки используется роут `counters/delete/grouping` который:
- удаляет все привязанные счётчики функцией `DeleteGroupingDevice`(countersModel)
- удаляет группировку функцией `DeleteGrouping`(countersModel)

## Обновление тарифов для садоводства (`User story 2`)

Обновление тарифа производится по следующему алгоритму

1. Отправляется запрос на роут `/update/tariff`
2. Запускается функция `UpdateTariff`(sntModel)
   1. Проверяется наличие данного тарифа по 3-м параметрам цены
   2. Если тариф существует - привязывает данный тариф к садоводству
   3. Если тарифа не существует - создаёт тариф и привязывает его к садоводству.

Для привязки тарифов ко всем садоводствам используется роут `/set/tariff` запускающую функцию `setTariff`(sntModel)

##  Виджеты(`User story 3`)

Для роли председатель, выводится виджет через который можно обновить тарифы(`User story 2`)

Для роли пользователь, выводятся следующие виджеты:

- Виджет с действующими тарифами
- Отдельные виджеты с последними показаниями для каждого счётчика, привязанного к его участкам
- Отдельные виджеты с последними потреблениями для каждого счётчика, привязанного к его участкам со сравнением со 
средним значением потребления в садоводстве

Данные для виджетов показаний и потреблений запрашиваются через роут `counters/widget`, набор счётчиков определяется 
используя функцию `getCountersByUser`(countersModel), для каждого найденного счётчика запускается функция:

- `getManual`(countersModel) для неавтоматических
- `getAuto`(countersModel) для автоматических

Визуально на отдельные виджеты раскладывается на фронте

## Вывод графиков потреблений (`User story 4`)

Данные для графиков запрашиваются по роутам

- `counters/chart/group` для всех счётчиков садоводства, запускающий функцию `getChartSnt`(countersModel) 
- `counters/chart/id` для выбранного счётчика пользователя, запускающий функцию `getChartId`(countersModel). Счётчики выбираются из 
выпадающего списка

Графики могут отображаться в кВт в час, рублях; в разрезе месяца(по дням) или года(по месяцам)

Для каждого графика выстраиваются 2 линии - общее потребление и среднее по садоводству.

##  Вывод показаний и потреблений (`User story 5`)

Вывод показаний и потреблений для всего садоводства или привязанных счётчиков пользователя. 
Данный выводятся таблица с данными по показаниям и потреблениям за указанный период(в кВт)
На фронте таблица сортируется по № участка, № счетчика, показаниям и потреблению

Данные запрашиваются через роут `counters/period`, запускающий функцию `countersMonthPeriod`(countersModel)
Если запрашивается для пользователя - выводятся только счётчики, привязанные к его участкам.
