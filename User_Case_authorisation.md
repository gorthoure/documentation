## Функция `login` (User story 2)

### Входные параметры

| Параметр   | Тип    | Описание               |
|------------|--------|------------------------|
| `login`    | string | Номер телефона         |
| `password` | string | Пароль в открытом виде |


### Описание

Функция проверяет:
- Совпадение логина и пароля с учетными данными разработчика.
- Наличие пользователя в черном списке.
- Валидность пароля.
- Наличие активной подписки.
- Наличие пользователя в БД портала
- Регистрацию на портале и в сервисе Амедиатеки, если пользователь отсутствует в БД портала
- Авторизацию на портале и в сервисе Амедиатеки

В случае успешной аутентификации устанавливает сессионные переменные и возвращает статус пользователя в формате JSON.


### Алгоритм выполнения (документация внешних функций в auth_api.md, amedia_registration&authorisation_by_API.md)

1. Если логин и пароль совпадают с данными технического входа:
    - Авторизовать как разработчика.    
    - Вернуть JSON.
2. Очистить логин от нечисловых символов.
3. Получить данные пользователя через функцию `checkNamePass` :
    - Если нет объекта ответа (`payload`) или объект не вернул данные о номере (`checkNamePass->payload->user->phone`), вернуть JSON с дефолтными данными.
    - Если в объекте указана блокировка (`checkNamePass->payload->in_blacklist`), установить флаг ЧС, вернуть JSON.
4. Сравнить входной параметр `password`(двойной md5) и пришедшие данные ответа `checkNamePass->payload->user->password`
   - Если пароль не совпадает, вернуть ошибку пароля.
   - Получить данные подписки через `checkSubs`, 
   - Если получен статус блокировки (`checkSubs->blocking`), вернуть статус активной подписки и финансовой блокировки              
5. Найти пользователя в БД портала, если пользователь не найден:
     - зарегистрировать пользователя на сервисе Амедиатеки по API
     - создать пользователя в БД портала  
6. Авторизовать найденного/созданного пользователя на сервисе Амедиатеки
7. Вернуть JSON успешной авторизации

### Выходные данные

Функция возвращает строку JSON со следующими полями:

| Поле         | Тип    | Описание                                              |
|--------------|--------|-------------------------------------------------------|
| `auth`       | string | `"Y"` — авторизован, `"N"` — нет                      |
| `active`     | string | `"Y"` — есть активная подписка, `"N"` — нет           |
| `blocking`   | string | `"Y"` — в черном списке или заблокирован, `"N"` — нет |
| `error_pass` | bool   | `true` — неверный пароль, `false` — пароль корректный |

Также в конечном объекте есть данные полученные при регистрации/авторизации на портале (`id`,`name`, `phone`) 
и данные полученные после авторизации на сервисе Амедиатеки
