## Получение данных по всем участкам за месяц (функция `getData`)

Получение данных по всем участкам за месяц(с 1 по последнее число месяца), с возможностью указать на сколько месяцев "отступить" от текущего.

По умолчанию - формируется за прошедший месяц 

### Параметры

| Параметр | Тип | Обязателен | Описание                |
|----------|-----|------------|-------------------------|
| group    | int | да         | id садоводства          |
| grouping | int | нет        | id группировки участков |
| offset   | int | нет        | отступ                  |

### Алгоритм работы

1. Формируется период для запрашиваемых данных
2. Формирование массива устройств
   - для группированных - только входящие в группу
   - без группировки - все устройства садоводства
3. Для каждого устройства из массива собираются данные пользователей через привязку устройства к участку и собственника
к участку. Среди собственников выбирается тот у которого указан контакт, если такого нет - любой. Если собственник не 
указан - не формируется
4. Для указанного садоводства запрашивается действующий на указанный период тариф
5. Для каждого устройства за указанный период запрашиваются:
   - последние (максимальные) данные показаний, если указана дата обнуления - вычитаются начальные данные      
   - сумма потреблений
   - вычисляются суммы в рублях за каждый тип потреблений и общая сумма

### Выходные данные

Массив с данными по каждому устройству

## Получение данных по конкретному участку за период (функция `PdfDataCounterPeriod`)

Получение данных по всем участкам за месяц(с 1 по последнее число месяца), с возможностью указать на сколько месяцев "отступить" от текущего.

По умолчанию - формируется за прошедший месяц 

### Параметры

| Параметр | Тип    | Обязателен | Описание                                |
|----------|--------|------------|-----------------------------------------|
| eui      | string | да         | серийный номер счётчика                 |
| from     | date   | да         | дата начала периода (period.start_date) |
| to       | date   | да         | дата конца периода (period.end_date)    |

### Алгоритм работы

1. Получение данных по устройству
2. Получение данных пользователей через привязку устройства к участку и собственника
к участку. Среди собственников выбирается тот у которого указан контакт, если такого нет - любой. Если собственник не 
указан - не формируется
3. Для садоводства к которому привязано устройства запрашивается действующий на указанный период тариф
4. За указанный период запрашиваются:
   - последние (максимальные) данные показаний, если указана дата обнуления - вычитаются начальные данные      
   - сумма потреблений
   - вычисляются суммы в рублях за каждый тип потреблений и общая сумма

### Выходные данные

Массив с данными по устройству

## Создание PDF(функция `createPdfAndReturnUrl`)

Создаёт PDF документ, записывает его на диск

Формирует строку "обоснование" для квитанции

### Параметры

| Параметр | Тип | Обязателен | Описание                                                                                                                                      |
|----------|-----|------------|-----------------------------------------------------------------------------------------------------------------------------------------------|
| item     | int | да         | Массив данных по устройству                                                                                                                   |
| type     | int | да         | отвечает за формирование пути для записи файла<br/> `group` для запроса по всем устройствам садоводства,<br/> `counter` для одного устройства |

### Выходные данные

Путь к созданному документу
